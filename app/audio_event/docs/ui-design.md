# Audio Event Detector — UI 设计文档

## 1. 概述

为 `audio_event` 音频事件检测 Demo 设计基于 LVGL 的图形化界面，目标平台为 NuttX RTOS (openvela)，屏幕规格 320×240，主要用于 goldfish 模拟器上的完整调试视图。

**设计风格**：仪表盘风格，科技感强，以实时数据可视化为核心。

**功能范围（基础版）**：
- 实时音频波形可视化
- 四类概率柱状图（敲击/咳嗽/背景/静音）
- 检测事件弹窗动画
- 状态指示（监听中/已触发/冷却中）

- 检测状态区域：绿色文字"监听中..."

- 持续时间：显示约 1.5 秒后进入冷却态

## 8. 数据流与刷新策略

```
audio_event_main (NuttX 主循环)
    │
    │  每 250ms (inference hop)
    │
    ├──→ 推理结果 (float probs[4])
    │       │
    │       ├──→ UI 更新概率柱状图 (4 个 lv_bar)
    │       │       └── lv_bar_set_value() + 动画
    │       │
    │       └──→ 检测器 (event_detector)
    │               │
    │               ├── fired=true → UI 显示事件弹窗
    │               │                   + 状态栏变红
    │               │                   + 呼吸灯启动
    │               │
    │               └── 进入冷却 → UI 显示冷却进度条
    │                               + 状态栏变黄
    │
    ├──→ 波形数据 (int16_t samples[])
    │       └── lv_canvas 绘制波形 (每 250ms 刷新)
    │
    └──→ 时间更新 (lv_label_set_text, 每秒)
```

### 刷新频率

| 数据 | 刷新周期 | 说明 |
|------|---------|------|
| 波形 | 250ms | 跟随 inference hop |
| 概率条 | 250ms | 每次推理后更新 |
| 检测状态 | 事件触发时 | 仅在检测到事件时更新 |
| 冷却进度 | ~33ms (30fps) | 倒计时需要平滑动画 |
| 状态指示灯 | 状态变化时 | 颜色切换 + 动画 |
| 时间 | 1000ms | 每秒更新 |


## 11. 与现有代码的集成点

在 `audio_event_main.c` 的主循环中，调用 UI 更新接口：

```c
/* 伪代码示意 */
process_window() {
    feature_extract(...);
    event_classifier_predict(..., probs);

    /* 更新 UI */
    audio_event_ui_update_probs(probs, 4);

    /* 检测判定 */
    event_detector_check(..., &detection);

    if (detection.fired) {
        audio_event_ui_notify_detection(detection.class_id,
                                        detection.confidence);
        audio_event_ui_notify_cooldown(cooldown_ms);
        event_alert_fire(...);
    }
}

/* 主循环每次读取音频块后 */
audio_event_ui_update_waveform(samples, count);

/* 每秒更新时钟 */
audio_event_ui_update_clock();
```

## 12. 后续扩展预留

基础版完成后，可按需扩展：

- **历史记录页**：检测事件列表，滑动切换
- **设置页**：触摸调节阈值、连续次数、冷却时间
- **频谱图模式**：切换波形为 mel 频谱瀑布图
- **统计图表**：各类事件检测次数柱状图/饼图

这些扩展可在当前布局基础上通过页面切换（`lv_scr_load_anim`）实现，不影响基础版架构。
