# 文档导航

本目录按用途组织，避免将赛题、设计方案、基线数据和调试手册混在一起。

## 阅读路径

- 初次了解项目：从[比赛说明/赛题说明.md](比赛说明/赛题说明.md)和仓库根目录 `readme.md` 开始。
- 构建、录音或排查硬件：阅读[使用与调试](使用与调试/)下的工具手册、异常说明和常见问题。
- 确认当前模型能力和性能：阅读[项目基线](项目基线/)中的事件口径与性能评估。
- 规划或实施复赛增量：阅读[复赛目标](复赛目标/)中的专项方案；其中关键词级联资料集中在[复赛目标/关键词识别](复赛目标/关键词识别/)。

## 文档状态约定

- `项目基线/` 中的数值和结论必须标明来源；模拟器结果不能替代真机结果。
- `复赛目标/` 中的文档默认是方案或测试计划。未在真机验证前，不应将其中的目标、参数或预期收益表述为已实现结果。
- 文档引用模型、训练数据、阈值、性能或功耗时，应同时给出对应版本、测试条件和原始日志/数据位置。
